### Installation
Before getting started, make sure you have the following tools installed on your machine:
[Git](https://git-scm.com), [Node.js](https://nodejs.org/en/).  
It's also recommended to use a code editor such as [VSCode](https://code.visualstudio.com/)

You must also run the [Python Backend](https://github.com/CaioPereir4/openai-bothealth) and [Node Backend](https://github.com/CaioPereir4/backend-bothealth) so this interface can consume their services.

<a id="how-to-use"></a>
### 🎲 Running the Interface

```bash
# Clone this repository
$ git clone <https://github.com/CaioPereir4/spa-bothealth.git>

# Navigate to the project folder in your terminal/cmd
$ cd spa-bothealth/

# Install dependencies
$ npm install

# Run the application
$ npm run start

# The server will start on port:4200 - access <http://localhost:4200>
